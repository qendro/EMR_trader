# A1 evaluated EMR phenotype boundary

`neuroevo.adapters.emr_phenotype.extract_evaluated` converts one genome from
the last **evaluated** generation into the platform's `BlockPlan`. It retains
the active full-grid indices and coordinates, uses evaluated FP32 input and
output weights, and maps valid sparse hidden connections into delayed blocks.
The graph view has immediate input/output edges, delayed hidden edges, tanh
hidden nodes, and linear output logits. Apply sigmoid to the logits for EMR
output parity. Zero active hidden positions are represented by empty blocks;
their sigmoid output is 0.5.

This interface intentionally reads `_cached_masks_A`, `_cached_W1`,
`_cached_W2`, `_cached_sparse_hh`, and `_last_eval` from the source-locked EMR
package. `population_substrates(state)` decodes the next generation after
selection and therefore cannot identify the evaluated weights. The extraction
checks layout, FP32/boolean dtypes, finite values, inactive positions, edge
endpoints, duplicate edges, and explicit node/edge capacities. It refuses
unavailable caches and unsupported activation, aggregation, or settling modes.
No threshold is applied again after EMR's discovery.

`settled_reference` independently computes the pinned upstream semantics in
FP64: each sample starts with zero hidden state, receives its input drive on
every settling step, and applies sigmoid after the final hidden step. The
platform's `block_step` instead uses one hidden update per environment step,
with the previous hidden state carried across steps. With recurrent edges
absent, sigmoid of a layered `block_step` output agrees with upstream's
feedforward result. These are separate execution profiles, not interchangeable
recurrent evaluations.

The [A1 tests](../tests/test_emr_phenotype.py) cover synthetic masks and
connections, exact graph edges and coordinate maps, a positive subnormal FP32
weight, empty hidden topology, capacity overflow, invalid caches, and one real
feedforward and recurrent generation from the pinned package. Real-generation
tests compare the extracted recurrent edge set and independently settled
outputs with upstream. The CPU suite passed 96 tests; the seven A1 tests also
passed on the RTX 3070 and RTX 3060 with their selected CUDA backends. The
current adapter converts evaluated phenotypes; A2
still needs a custom evaluation/tell seam to evolve them under persistent
layered rollouts, then its own G9 pilot and acceptance runs.
